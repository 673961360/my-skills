# 外部短评采集方式

本文档记录从外部 QT 平台（森浦、通达信、快确）采集现券、资金、一级发行三类短评的方法与数据源配置。

## 取聊天记录方式

```sql
SELECT *
FROM ats.t_repo_robot_chatmessage t
WHERE t.MSG_DATE = 20260618
```

查询当天的所有实时原文，`channel` 字段含义：

| channel 值 | 来源 |
|-----------|------|
| 1 | 森浦 QT |
| 3 | 通达信 QT |
| 4 | 快确 QT |

## 短评生成方式

建议为抽取 **17 点后**涉及以下主题的短评：

- 资金
- 现券
- 一级发行

> **注意**：同一个人应去重，然后基于这些人的观点汇总成自己的观点。
