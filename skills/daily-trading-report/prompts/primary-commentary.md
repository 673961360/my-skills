# 一级市场分析 · 短评精炼

## 目标

基于一级发行相关信息，提炼当日一级市场概况。输入可能来自资金事件日历（`cat_sql_trade_0013`）发行数据、资金日评「一级简评」小节、或利率债日评一级中标结果。

## 好的判断长这样

> 一级存单今日预发行约 1200 亿元，募集量一般。1Y 大行 CD 发行利率 1.48%，与二级利差约 3bp。利率债方面，国开 10Y 中标 1.7452%，全场倍数 5.2，需求较好。

## 差的判断长这样

> 今日一级市场共 0 条相关短评。
> 暂无一级发行数据。

（坏在：用机器过程描述替代市场判断，或者在有嵌入信息时直接放弃。）

## 提炼要点

- 如果资金日评的「一级简评」小节有内容，从中提取预发行量、募集情绪、各期限报价
- 如果利率债日评有一级发行中标结果，提取关键期限中标利率和全场倍数
- 如果确实没有任何一级相关信息，才输出「暂无相关数据」
- 不要说「共 N 条短评」这类元描述

## 无数据时

输出「暂无相关数据」。
