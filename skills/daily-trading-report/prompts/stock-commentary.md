# 权益市场分析 · 短评生成

## 目标

写一段权益市场总结，让读者把握当日 A 股行情的**增量判断**——成交额、板块轮动、资金流向、驱动因素。

> 指数点位和涨跌幅**上方指数表已有**（脚本从新浪/腾讯实时采集），文字不复述绝对点位。

## 与指数表的分工

| 内容 | 来源 |
|------|------|
| 四大指数点位、涨跌幅 | 上方指数表，**文字不重复** |
| 两市成交额、放量/缩量 | WebSearch |
| 领涨/领跌板块、市场主线 | WebSearch |
| 主力资金流向、驱动因素 | WebSearch |

文字最多提一句**相对判断**（如「创业板领涨」「成长类占优」），不写绝对点位。

## 数据获取（WebSearch）

WebSearch 走国内索引，能取到当日 A 股收盘数据，但**查询策略决定成败**：

1. **主查询（最稳）：域名限定 + 不带日期**
   - query：`A股 收盘 成交额 领涨板块`
   - allowed_domains：`eastmoney.com, sina.com.cn, stcn.com, cs.com.cn, yicai.com`
   - 直击东方财富/证券时报等收盘播报页，数据最全。
2. **备查询：带日期 + 时效过滤**
   - query：`YYYY年M月D日 A股 收盘 成交额 板块`
3. **禁用：精确点位反查**（如「上证指数 4163」）——媒体报道用涨幅和整数关口，不含精确收盘点位，搜不到。
4. **时机**：盘后 1-2 小时内引擎索引可能未建；域名限定也搜不到时，过几小时或次日再搜，命中率显著上升。

## 交叉验证与噪声处理

WebSearch 摘要聚合多源，**有噪声**：

- **涨幅**：以脚本表格值为准（权威），不用 WebSearch 的。
- **成交额**：不同来源尾数可能差几十亿（如 3.74 vs 3.76 万亿），取量级一致即可。
- **板块**：不同查询表述可能不同（如「算力金属」vs「小金属/稀土」），取**方向一致**的主线（如「金属+券商+科技」），不必精确排序。
- **关键数字**：两个查询一致才采信；不一致取量级，或换查询再查一次。

## 好的判断长这样

> A 股放量上涨，两市成交约 3.7 万亿元，较前日放量约 4000 亿，创历史次高。金属板块全线走强（小金属、稀土、能源金属），证券、保险跟进；科技风格延续，创业板领涨。主力资金净流出约 170 亿，上涨中存获利了结压力。

（好在不复述点位；全是表格给不了的判断：成交、板块、资金、驱动。）

## 差的判断长这样

> 今日 A 股四大指数全线收涨，上证指数涨 1.78% 报 4163.10 点，深证成指涨 2.13%，创业板指涨 2.52%，科创50涨 1.96%。

（坏在：把上方指数表逐字抄一遍，零增量。）

> 根据搜索结果，今日 A 股市场有一定波动，指数有所上涨，市场呈现分化态势。

（坏在：模糊空洞，没成交额、没板块、没驱动。）

## 提炼要点

- 文字只写表格没有的：成交额/放量、领涨领跌板块、资金流向、驱动因素
- 涨幅引用表格，最多加一句相对判断（谁领涨），不写绝对点位
- 必须有成交额（带放量对比更好）、必须有板块方向
- 关键数字交叉验证，噪声大的取量级/方向
- 不要说「根据搜索结果」「据悉」这类元描述

## 无数据时（降级阶梯）

1. 域名限定查询 + 带日期查询都试过仍无当日数据 → **不得用旧闻或附近日期冒充当日**（缺失数据不得编造）。
2. 基于脚本已采的真实指数（表格），写一句客观涨跌 + 相对判断，并诚实标注缺口：
   > 今日 A 股四大指数全线收涨，创业板指领涨；成交额与领涨板块数据待盘后更新。
3. 不要复述表格绝对点位，也不必丢一句「外部短评暂未获取」了事（表格已有数据，不算完全无数据）。
