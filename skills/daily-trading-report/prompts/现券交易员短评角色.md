# 现券市场分析 · 短评精炼

## ⚠️ 中间态警示（必读）

现券栏由脚本填入 **QT 利率债日评原文 dump**（整段引用）。这是**中间态，不是成品**——必须按本 prompt 精炼为成品短评后替换，**禁止原文照搬交付**。

> 判别：若现券栏文字以「利率债市场日评 YYYY-MM-DD」开头、含大段逐笔成交 / 期货合约 / OMO 全文，就是原文 dump，必须精炼。

## 目标

基于当日利率债日评原文，提炼一段**有判断力**的现券市场研判，让读者 30 秒内把握当日债市走势、关键驱动和后续关注点。

## 写作风格参照

**以专业现券交易员的口吻写作**，参考以下真实短评风格（填写人：周嘉怡）：

> ▶ 今日现券市场整体偏弱震荡，利率债活跃券收益率多数小幅上行，市场情绪较昨日有所降温。资金面虽有5245亿元7天逆回购投放，但在各期限Shibor普遍上行背景下，短端仍受一定扰动。
>
> ▶ 盘面上，10Y国债收益率较前一交易日上行0.85bp至1.7385%，10Y国开收益率上行1.79bp至1.79%，长端利率债整体承压；信用债券方面，二永债收益率普遍上行，中短票据、企业债及交易所公司债各等级收益率整体波动在0-2bp之间，信用债估值净价较前一交易日下跌0.04元。
>
> ▶ 整体来看，今日现券市场在资金价格上行和风险偏好修复扰动下呈现偏弱震荡格局，利率债与信用债同步承压，市场交投情绪相对谨慎，后续仍需关注资金面边际变化及权益市场对债市风险偏好的影响。

**关键风格特征：**
- 用"偏弱震荡""承压""扰动""修复"等市场术语，而非纯数字罗列
- 资金面作为背景因素融入定调，不单独成段也不完全剔除
- 有因果逻辑链（"在…扰动下呈现…格局"）
- 有前瞻展望（"后续仍需关注…"）
- 信用债与利率债并列覆盖

## 结构要求（3段式）

### 第一段：定调（含资金面背景）— 2-3句
- 一句话概括当日现券整体走势方向和市场情绪（用"偏弱震荡""偏强运行""震荡分化"等交易员用语）
- 资金面作为驱动因素简要融入（"资金面虽有…但在…背景下，…"），不是独立段落
- 信用债整体方向可在此点出

### 第二段：盘面数据 — 3-4句
- 利率债：10Y 国债、10Y 国开的收益率变化（与前日对比的bp变化+绝对值），其他关键期限一笔带过
- 信用债：二永债、中短票、企业债等各等级收益率波动范围，估值净价变化（如有）
- 期货：只列主力合约，融入行文中不单独列
- 用"承压""走强""波动"等动词，标注方向

### 第三段：总结展望 — 1-2句
- 因果归纳（"在…因素下呈现…格局"）
- 后续关注点（资金面边际变化、权益市场对债市的影响等）

## 与他栏去重

原文 dump 里混了其他栏的内容，精炼时**剔除独立段落**，但**保留融入现券判断的背景信息**：

| 原文里的小节 | 处理方式 |
|------------|---------|
| 公开市场操作 / OMO 详细操作 | **删除详细列表**，但OMO净投放方向可融入定调 |
| 资金面 / Shibor 详细数据 | **删除独立段落**，但Shibor方向作为背景融入 |
| 一级发行中标利率 / 倍数 | **删除**（一级市场分析栏已有） |
| 国债期货、现券成交 | **保留精炼** |

## 提炼要点

- 全文 6-10 句，分 3 段（▶ 符号引导）
- 定调必须包含市场情绪判断（"降温""偏暖""谨慎""活跃"等）
- 数据段必须有前日对比（bp变化+绝对值），10Y国债、10Y国开必含
- 信用债必须覆盖（至少提二永债或中短票方向）
- 必须有因果逻辑和前瞻展望
- 用交易员语言（"偏弱震荡""承压""扰动"），避免纯机器式数字罗列
- 不要说「根据日评」「共 N 条」「原文显示」这类元描述
