# 资金市场分析 · 短评精炼

## 触发条件（先判断是否需要本 prompt）

04 资金市场「资金面状况」有两种渲染路径：

- **结构化时段表**（早盘 / OMO后 / 午前 / 午后 / 尾盘 × 隔夜/7天/14天/市场状态）= 脚本已成品，**无需本 prompt**，跳过。
- **QT 原文 dump**（整段资金日评原文）= 中间态，**按本 prompt 精炼替换**。

> 判别：若「资金面状况」已是表格（有「时段」列），不动；若是整段文字，就是原文 dump，按下精炼。

## 目标

基于当日资金日评原文，提炼一段资金面研判，让读者 30 秒内把握当日资金市场全貌。

## 好的判断长这样

> 资金面整体均衡。早盘银行融出隔夜-14天，隔夜加权约 1.45%，7 天 1.43-1.48%。OMO 净回笼 1205 亿元。存单足年大行成交于 1.475% 附近，较前日上行 0.5bp。

## 差的判断长这样

> 今日资金面整体均衡。隔夜报于加权-+5bp左右，5-7天报于1.41%-加权，14天部分报于加权，3个月及以上期限需求以拆借为主。非银隔夜报于加权-1.48%附近，7天报于1.43-1.48%附近。午盘后隔夜报于加权-1.47%附近。直至收盘市场无明显波动。（来源：中诚BGC · 17:14:25 日评）

> 根据资金面消息，共 N 条短评，关键词出现频次：均衡 3 次、偏紧 0 次...

（第一段坏在：把日评原文的逐笔报价逐条照搬，没有提炼。第二段坏在：用机器过程描述替代市场判断。）

## 提炼要点

- 如果日评含多个小节（OMO、资金面、存单、票据），只取与资金面判断相关的内容
- 票据小节不属于资金市场分析，丢弃
- 逐笔成交明细、机构名单、问候语，丢弃
- 数值取代表性区间即可，不需要逐条报价
- 不要说「根据消息」「从日评来看」「共 N 条」这类元描述

## 无数据时

输出「暂无有效消息」。
