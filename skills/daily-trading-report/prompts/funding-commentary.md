# 资金市场分析 · 短评精炼

## 触发条件（先判断是否需要本 prompt）

04 资金市场「资金面状况」渲染路径：

- **时段表 + `analysis-box` 原文 dump**（表格后有整段文字）= 中间态，**按本 prompt 精炼替换**。
- **时段表 + `analysis-box` 已是精炼文字**（含"整体状态""市场特征总结"两段）= 已成品，跳过。
- **无数据**（`available=False`）= 跳过。

> 判别：若表格后 `analysis-box` 内容是整段原文（含逐笔报价、来源标注），按下精炼；若已是 `整体状态：...` 格式，跳过。

## 目标

基于当日资金日评原文，提炼**两段文字**，让读者快速把握当日资金市场全貌。

## 输出格式

严格按以下格式输出，**不要添加任何其他内容**（包括开头问候、结尾总结、代码块标记）：

整体状态：[时间线概括，30 字以内]

市场特征总结：[定性分析 + 原因解释，50-80 字]

## 示例 1

整体状态：早盘资金面均衡偏松，OMO 后边际收敛，午后利率上行，尾盘转均衡。

市场特征总结：央行大额净回笼 + 临近跨月是主因。跨月 9d/14d 成本明显抬升，非银融资偏贵。

## 示例 2

整体状态：早盘偏紧，午盘维持偏紧态势，尾盘大行融出增多转均衡。

市场特征总结：政府债缴款 + 跨月因素导致资金面收敛。隔夜加权利率较前日上行 2bp。

## 提炼要点

- **整体状态**：时间线概括（早盘→OMO 后→午前→午后→尾盘），30 字以内
- **市场特征总结**：
  - 解释资金面走势的原因（OMO 净投放方向、跨月因素、政府债缴款等）
  - 只描述关键品种的价格变化（隔夜、7D、跨月品种中选代表性的）
  - 给出结论判断（如"跨月成本抬升""非银融资偏贵""资金面整体均衡"等）
- 与表格数据互补：表格展示各时段报价，文字补充原因和判断
- 逐笔成交明细、机构名单、问候语，丢弃
- 不要说"根据日评""从原文来看""共 N 条"这类元描述

## 无数据时

不替换，保持原状。
