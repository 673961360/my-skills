# 学习模式 · 详细设计文档

> 版本 v1.0 | 日期 2026-06-23

## 一、目标与使用场景

**目标**：在交易日报 HTML 上叠一层交互式的"数据来源说明"，让业务同事（交易员/固收研究员）点击板块标题就能看到每个数字/每段文字的数据来源和加工方式。

**使用方式**：一次生成一份参考文档（不是每日生成）。

```bash
uv run python scripts/generate_report.py --date 20260623 --learning
# → 输出 reports/2026-06-23-daily-learning.html
```

## 二、交互设计

### 2.1 触发

| 行为 | 效果 |
|------|------|
| 点击板块标题栏（如 `01 交易数据汇总`） | 右侧滑出数据来源面板，展示该板块的数据血缘 |
| 再次点击同一标题栏 | 面板收回 |
| 点击另一个板块标题栏 | 面板内容切换到新板块（不收回再滑出，直接切换内容） |

### 2.2 面板

- 固定在页面右侧，宽度 320px
- 滑出/收回动画 250ms ease
- 面板内滚动独立于主内容
- 移动端（≤768px）面板变为底部抽屉，从下往上滑出

### 2.3 视觉标识

标题栏右侧增加一个小图标 🛈（或 `ⓘ`），标明"可点击查看来源"：

```
┌──────────────────────────────────────────┐
│ 01  交易数据汇总                    ⓘ   │  ← 整行可点击
└──────────────────────────────────────────┘
```

学习模式下标题栏增加：
- `cursor: pointer`
- hover 时背景色微变（`#1a5c96` → `#1f6fae`）
- 右侧 `ⓘ` 图标

### 3.2 各板块独立布局

每个板块的面板布局可根据内容特点独立设计，不强制统一格式。

#### 01 交易数据汇总

```
📋 数据来源

┌─ 概要 ─────────────────────┐
│ 当日全部有效O32指令，按     │
│ 买/卖×四类品种统计          │
└────────────────────────────┘

🔗 来源
  O32 指令系统 → AI Gateway API
  （每日自动拉取）

⚙️ 加工
  · 已撤销指令：不计
  · 多次修改：只取最后一次
  · 回购：仅统计银行间市场
  · 金额单位：亿元

✅ 可信度：系统计算，高可信

⚠️ 注意
  指令金额 ≠ 成交金额；
  汇总以成交金额为主口径
```

#### 02 交收数据汇总

```
📋 数据来源

┌─ 概要 ─────────────────────┐
│ 当日16:30后下达的正回购     │
│ 指令，反映临收盘应急融资    │
└────────────────────────────┘

🔗 来源
  实时正回购询价系统 → AI Gateway API

⚙️ 加工
  · 仅保留16:30后指令
  · 产品名已脱敏（创金/合信→*）
  · 金额：元→万元

✅ 可信度：系统采集，高可信

⚠️ 注意
  "X点X分未到账"表示指令下达时间晚于16:30；
  不含16:30前正常交收的正回购
```

#### 03 市场预测汇总

```
📋 数据来源

⚠️ 这不是量化模型
  预测基于情绪判断+动量外推，
  方向有参考价值，点位精确度低

🔗 信号来源
  · 回购利率 → 银行间实时行情
  · OMO净投放 → 资金事件日历
  · 资金情绪 → QT日评/外部短评
  · 国债收益率 → 中国货币网曲线
  · 权益指数 → 新浪/腾讯双源

⚙️ 方法
  多路信号打分 → 方向判断
  → 当前点位+固定步长外推区间

✅ 可信度
  方向判断 ⭐⭐⭐ 中等
  点位区间 ⭐⭐   低（非精确预测）
```

#### 04 资金市场分析

```
📋 数据来源

┌─ 概要 ─────────────────────┐
│ 分两块：                    │
│ ①公开市场操作（OMO）表      │
│   来自资金事件日历          │
│ ②资金面状况                │
│   来自QT资金日评            │
└────────────────────────────┘

📊 数字从哪来（OMO表）
  · 央行逆回购/MLF投放与到期 → 资金事件日历
  · 净投放 = 投放 − 到期
  · 金额单位：亿元

📝 文字从哪来（资金面状况）
  · QT日评 → 脚本提取时段×品种 → 结构化表
  · AI精炼为"整体状态"+"市场特征"两段判断
  · 精炼素材：机构资金日评

✅ 可信度
  OMO数字  ⭐⭐⭐ 高（央行公开数据）
  资金面表 ⭐⭐⭐ 高（机构报价整理）
  精炼判断 ⭐⭐   中（AI提炼，供参考）
```

#### 现券市场分析

```
📋 数据来源

┌─ 概要 ─────────────────────┐
│ 机构利率债日评的精炼判断，  │
│ 覆盖国债期货、活跃券成交、  │
│ 盘中节奏和情绪              │
└────────────────────────────┘

🔗 来源
  QT聊天流中的利率债日评

⚙️ 加工
  · 脚本召回全文 → 去URL/空行
  · AI按模板精炼为5-7句研判
  · 剔除与资金栏重复内容
    （OMO、Shibor、一级中标）

✅ 可信度
  精炼判断 ⭐⭐ 中（AI提炼机构观点）
  原始素材 ⭐⭐⭐ 高（机构日评原文）

⚠️ 注意
  不含信用债；如某日无利率债日评，
  会通过外部搜索补充
```

#### 权益市场分析

```
📋 数据来源

┌─ 概要 ─────────────────────┐
│ 分两块：指数表（系统算） +  │
│ 行情总结（AI撰写）          │
└────────────────────────────┘

📊 指数表
  🔗 新浪财经 → 腾讯财经（备源）
  ✅ 实时抓取，高可信
  · 上证指数、深证成指
  · 创业板指、科创50

📝 行情总结
  🔗 AI通过Web搜索获取当日A股收盘
  ⚙️ AI按模板写4-6句：
    量能、领涨板块、领跌板块、
    资金方向、风格判断
  ✅ 覆盖面广，但偶尔滞后

⚠️ 注意
  指数点位以上方表格为准；
  总结文字是AI查的，不编造
```

#### 一级市场分析

```
📋 数据来源

┌─ 概要 ─────────────────────┐
│ 当天一级市场发行情况：      │
│ 卡片（汇总）+ 明细表         │
│ + AI精炼【一级简评】         │
└────────────────────────────┘

📊 数字从哪来
  🔗 资金事件日历 → 发行与到期事件
  ⚙️ 只取发行方向，到期不算
  · 汇总卡：利率债/地方债/NCD
  · NCD卡片取次日预发行数据
  ✅ 系统计算，高可信

📝 文字从哪来
  🔗 资金日评【一级简评】小节
  ⚙️ 脚本提取 → AI精炼为判断总结
  ✅ 中可信（AI提炼机构观点）

⚠️ 注意
  当日无发行 → 显示"暂无相关数据"
```

### 4.6 JS 逻辑

```javascript
(function() {
  const panel = document.getElementById('learning-panel');
  const panelBody = document.getElementById('learning-panel-body');
  const closeBtn = panel.querySelector('.learning-panel-close');
  const overlay = document.getElementById('learning-overlay');
  
  // 从 data/learning-annotations.json 注入的 JS 变量
  const ANNOTATIONS = {{ annotations | tojson }};
  
  let activeSection = null;
  
  // 点击标题栏 → 展开/切换面板
  document.querySelectorAll('.learning-trigger').forEach(trigger => {
    trigger.addEventListener('click', function(e) {
      const sectionKey = this.dataset.panel;
      if (activeSection === sectionKey) {
        closePanel();
      } else {
        openPanel(sectionKey);
      }
    });
  });
  
  function openPanel(key) {
    const data = ANNOTATIONS[key];
    if (!data) return;
    renderPanelContent(data);
    panel.classList.add('open');
    overlay.classList.add('visible');
    activeSection = key;
    // 高亮当前标题栏
    document.querySelector(`[data-panel="${key}"]`).classList.add('active');
  }
  
  function closePanel() {
    panel.classList.remove('open');
    overlay.classList.remove('visible');
    if (activeSection) {
      document.querySelector(`[data-panel="${activeSection}"]`)
        .classList.remove('active');
    }
    activeSection = null;
  }
  
  closeBtn.addEventListener('click', closePanel);
  overlay.addEventListener('click', closePanel);
  
  // 移动端适配
  function renderPanelContent(data) { /* 按板块渲染 */ }
})();
```
