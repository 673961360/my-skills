## O32 字段 → 日报栏目映射

> 从 `scripts/data_collector.py` 提取的实际使用字段。

| O32 字段 | 类型 | 日报栏目 | 用途 |
|---------|------|---------|------|
| `业务分类` | VARCHAR | 交易数据汇总 | 分组维度（交易所业务/银行间业务等） |
| `委托方向` | VARCHAR | 交易数据汇总 | 分组维度（取值见 `rules.md` 委托方向口径） |
| `指令状态` | VARCHAR | 交易数据汇总 | 过滤条件（已撤销且未成交不计；部分/全部成交仍统计） |
| `成交状态` | VARCHAR | 交易数据汇总 | 过滤条件（已撤销时区分未成交/部分成交/全部成交；缺失视为未成交） |
| `指令金额` | NUMBER | 交易数据汇总 | 金额列（总指令金额参考口径，SUM） |
| `成交金额` | NUMBER | 交易数据汇总 | 金额列（分类金额/总成交金额主口径，SUM） |
| `指令下达时间` | NUMBER | 交易笔数 | 按小时分组（HHMMSS → 小时） |

### 聚合逻辑

| 日报栏目 | 聚合方式 | 代码函数 |
|---------|---------|---------|
| 交易数据汇总 | 四类(现券/资金/权益/一级) × 买/卖，SUM(成交金额) + COUNT(有效指令)；另 SUM(指令金额) 作总指令金额参考 | `aggregate_trade_overview()` |
| 交易笔数 | GROUP BY HOUR(指令下达时间), COUNT(有效指令) | `aggregate_trade_count_by_hour()` |
| 交易金额(按方向) | 当日方向 × SUM(成交金额)；回购仅统计银行间 | `aggregate_trade_amount_by_direction()` |

### 数据缺口

| 日报栏目 | 缺口 | 说明 |
|---------|------|------|
| 权益市场分析 | 无 O32 权益类指令 | O32 以债券回购为主，无股票/基金指令 |
| 市场预测汇总 | 部分外部源已接入，一级 CD 源待确定 | 当前版本不做趋势/区间预测准确率；资金当日行情使用 QT/外部短评情绪，OMO 用 `cat_sql_trade_0013`，现券/权益行情使用外部行情源 |

## QT 短评：数据源真实结构与字段映射

> **关键修正**：QT 表（`ats.t_repo_robot_chatmessage`）本质是**交易报价/询价聊天流**，不是短评库。6.18 实测单日 13.19 万条中 99%+ 是报价单、成交回报、机器人公告、寒暄；真正的市场短评仅 25 条（去重 8 篇）。直接对全表做关键词分类会把报价当短评（见下方「现有逻辑缺陷」）。

### QT 字段

| QT 字段 | 类型 | 用途 |
|---------|------|------|
| `MSG_DATE` | NUMBER | 消息日期（YYYYMMDD，过滤条件） |
| `MSG_TIME` | NUMBER | 9 位整数 HHMMSSfff（排序；处理见 `rules.md` 踩坑表） |
| `CHANNEL` | NUMBER | 频道（1=森浦QT, 3=通达信QT, 4=快确）；**同篇日评跨频道重复** |
| `CONTENT` | VARCHAR2 | 消息原文（报价/日评混存，需按下方口径区分） |
| `MSG_SEND_NAME` | VARCHAR2 | 发送人；**同篇日评有发送人名变体**，不能用作去重键 |
| `MSG_GROUP_NAME` | VARCHAR2 | 群名称 |

### 短评召回口径（已接入 `db_client.fetch_daily_commentary`）

短评必须**先按时段关键词从报价噪音里召回**，再做主题分类。6.18 实测 LIKE 命中：

| 召回词 | 命中 | 去重独立篇 | 说明 |
|--------|------|-----------|------|
| `%日评%` | 19 | 7 | 收盘日评（17-18 时），主力来源（df=6） |
| `%早评%` | 3 | 1 | 盘前 ~09:20，单用「日评」会漏 |
| `%午评%` | 3 | 1 | 午间 ~13:00，单用「日评」会漏 |
| `%简评%` / `%述评%` / `%短评%` | 3/1/1 | 0（嵌入） | 均为日评正文措辞（如【一级简评】小节、资金短评），被「日评」覆盖 |
| `%盘后%` | 6 | 0（冗余） | 日评正文含「盘后」字样，非独立品类 |
| 晨评/盘前评/收盘评/闭市评/复盘/小结 | 各 0 | — | 6.18 无此叫法 |
| ⚠️ `%评%`（宽泛） | 海量 | — | **禁用**：命中「主体/债项/信用评级」等债券术语 |
| ⚠️ `X报`（日报/周报/早报…） | 多为噪音 | — | 「最优报价/发布/上报」噪音，无评述价值（6.18「日报」仅 df=1） |

- **完整召回**：`CONTENT LIKE '%日评%' OR '%早评%' OR '%午评%'` → 25 条 → 去重 8 篇
- **性能**：LIKE 扫 13 万行单次约 0.17s（18 词一组 3.1s）
- **跨频道去重**：同篇日评发 ch1/3/4 且发送人名有变体 → 按 **CONTENT 原文完全相同**去重（等价 `DISTINCT CONTENT`）；早/午/日评原文不同，不会误并
- **数据驱动穷尽扫描**（6.18 长消息≥150 字去重 1989 篇，正则统计「X评/XX评/X报」）：评述标识仅 日评(df=6)/早评(df=1)/午评(df=1) 主力 + 简评/述评/短评 低频嵌入；「评」高频项主体/债项/信用均为「评级」噪音，「报」高频项最优/发布均为报价噪音。**未发现其他独立评述品类，召回集合已完备**。

### 日评时段 × 主题矩阵（6.18 实测 8 篇）

| 时段 | 主题 | 篇数 | 典型来源 |
|------|------|------|---------|
| 盘前 ~09:20 | 资金/存单 | 1 | 上田八木【资金早评】 |
| 午间 ~13:00 | 资金/存单 | 1 | 上田八木 资金存单午评 |
| 收盘 17:00 | 资金/存单 | 5 | 吕浩轩/潘蕊·上田八木/中诚宝捷思/中诚BGC/平安利顺 |
| 收盘 18:00 | 现券(利率债) | 1 | 信唐-徐钰涵 利率债市场日评 |

早/午/日评是同主题的**递进更新**（同一机构一天发多次）。日评正文**结构化**（含【公开市场操作】【资金面】【一级存单】【一级简评】等小节），已覆盖 OMO 净投放、资金面情绪、各期限利率、国债期货、一级存单评述，日报所需字段基本齐全。

### 主题二次分类（对召回的日评，按标题）

- **资金面**：标题含「资金」「货币市场」「存单」
- **现券**：标题含「利率债」「国债」「现券」（6.18 仅利率债 1 篇，**无信用债日评**）
- **一级发行**：无独立一级日评；但**一级存单评述嵌在资金存单日评的【一级简评】小节**（明日预发行量、募集量、各期限报价，近 10 天 7 条命中均为正文嵌入、0 条独立）；利率债一级见「利率债市场日评」+ eBOND 机器人公告

### 采集与生成逻辑（已重构）

**脚本层**（`db_client.fetch_daily_commentary()` + `data_collector.generate_market_commentary()`）：
SQL `日评/早评/午评` 召回 → CONTENT 原文去重 → 标题分主题 → 选代表篇 → 原文输出（去 URL/空行清洗）。脚本产出的 `market_commentary` 为原文 dump，不做精炼。

**精炼层**（Claude 执行）：
脚本输出 HTML 后，Claude 读取资金/现券/一级栏的原文 dump，按 `prompts/` 模板精炼为 3-5 句判断性总结；权益栏由 Claude 通过 WebSearch 获取 A 股行情后按 `prompts/stock-commentary.md` 生成总结。精炼结果直接编辑 HTML 替换。一级无独立日评，但从资金日评的【一级简评】小节提取原文 dump 供精炼。

| 栏目 | Prompt 文件 | 输入来源 |
|------|-----------|---------|
| 资金市场分析 | `prompts/funding-commentary.md` | QT 资金日评原文 dump |
| 现券市场分析 | `prompts/bond-commentary.md` | QT 现券日评原文 dump |
| 一级市场分析 | `prompts/primary-commentary.md` | 资金日评【一级简评】小节原文 dump + 0013 发行数据 |
| 权益市场分析 | `prompts/stock-commentary.md` | WebSearch A 股收盘数据 |

原 `categorize_messages` 全表关键词匹配（误把报价当短评）已移除。

> 权益市场无 QT 日评，需 WebSearch（见下方外部数据源）。
