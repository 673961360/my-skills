# 字段映射与数据缺口

> 查表参考：字段含义、栏目映射、分类关键词、数据缺口。按 CLAUDE.md「文档卫生」，查表参考归本文件，操作/口径/踩坑归 `rules.md`。

## O32 字段 → 日报栏目映射

> 从 `scripts/data_collector.py` 提取的实际使用字段。

| O32 字段 | 类型 | 日报栏目 | 用途 |
|---------|------|---------|------|
| `业务分类` | VARCHAR | 交易数据汇总 | 分组维度（交易所业务/银行间业务等） |
| `委托方向` | VARCHAR | 交易数据汇总 | 分组维度（取值见 `rules.md` 委托方向口径） |
| `指令状态` | VARCHAR | 交易数据汇总 | 过滤条件（排除"撤销"） |
| `指令金额` | NUMBER | 交易数据汇总 | 金额列（SUM） |
| `成交金额` | NUMBER | 交易数据汇总 | 金额列（SUM） |
| `指令下达时间` | NUMBER | 交易笔数 | 按小时分组（HHMMSS → 小时） |
| `指令价格 (回购为利率)` | NUMBER | 交易金额 | 利率值（AVG/MAX/MIN） |
| `回购天数` | NUMBER | 交易金额 | 品种分类（1=R001, 7=R007, 14=R014） |

### 聚合逻辑

| 日报栏目 | 聚合方式 | 代码函数 |
|---------|---------|---------|
| 交易数据汇总 | GROUP BY (业务分类 + 委托方向), SUM(指令金额), COUNT(*) | `aggregate_trade_overview()` |
| 交易笔数 | GROUP BY HOUR(指令下达时间), COUNT(*) | `aggregate_trade_count_by_hour()` |
| 交易金额 | GROUP BY 回购天数，AVG/MAX/MIN(指令价格) | `aggregate_trade_prices()` |

### 数据缺口

| 日报栏目 | 缺口 | 说明 |
|---------|------|------|
| 权益市场分析 | 无 O32 权益类指令 | O32 以债券回购为主，无股票/基金指令 |
| 市场预测汇总 | 外部源已确定，尚未接入自动抓取 | 当前版本不做趋势/区间预测准确率；资金面/现券预测已先使用 O32、资金事件日历、QT 情绪生成规则化预测，外部来源作为收益率曲线和公开市场操作补强 |

## 交收数据汇总 · 应急回购数据源（cat_api_trade_0008，待接入）

> 取数方法已明确，尚未接入代码。用于「02 交收数据汇总」的应急回购子项。

| 项 | 内容 |
|------|------|
| 接口 | `cat_api_trade_0008`（查询实时正回购询价结果） |
| 用途 | 「02 交收数据汇总」应急回购子项 |
| 筛选条件 | `inqResStatusText` ∈ {有效, 已下达} AND `sideCodeText` = 正回购 AND `opTime` ≥ "160000" |
| 应急判定 | `opTime` 在 16:00 及以后视为应急回购 |
| 脱敏建议 | 应急产品按出现顺序编号为「产品1、产品2…」（序号代号） |
| 与 0021 关系 | `cat_api_trade_0021`（进度汇总）目前用不上；应急回购数据取自 0008 |
| 状态 | 仅记录取数方法与脱敏建议，待接入验证。接入后需同步更新 `template-contract.md`「02 交收数据汇总」数据源（当前标注「进度汇总 API」，实际改用 0008） |

### 脱敏说明

「产品1、产品2」是**按出现顺序编号的序号代号**，与 `scripts/desensitize.py` 现有脱敏（产品代码前两位换 `**`、产品名称按 创金/合信 + 括号规则）是两套逻辑。接入时需新增编号方法（如 `mask_to_index()`）或在展示层编号，不得复用现有脱敏函数。

## QT 短评字段映射

| QT 字段 | 类型 | 用途 |
|---------|------|------|
| `MSG_DATE` | NUMBER | 消息日期（YYYYMMDD，过滤条件） |
| `MSG_TIME` | NUMBER | 9 位整数 HHMMSSfff（排序；处理见 `rules.md` 踩坑表） |
| `CHANNEL` | NUMBER | 频道（1=森浦QT, 3=通达信QT, 4=快确） |
| `CONTENT` | VARCHAR2 | 短评原文 |
| `MSG_SEND_NAME` | VARCHAR2 | 发送人 |
| `MSG_GROUP_NAME` | VARCHAR2 | 群名称 |

### 分类关键词

定义在 `scripts/db_client.py::categorize_messages()`，按顺序匹配（命中即停）：

- **资金面**：回购、资金、头寸、融出、融入、R001/R007/DR001/DR007、利率、加权、央行、逆回购、MLF、OMO、投放、回笼
- **现券**：现券、债券、收益率、估值、成交、活跃券、国债、政金债、信用债、BP、YTM、利差
- **一级发行**：一级、发行、投标、新债、招标、边际、倍率、募
- **其他**：未命中

> 权益市场无 QT 关键词，需 WebSearch（见下方外部数据源）。

## 外部数据源（活跃缺口）

| 栏目 | 数据源 | 获取方式 | 降级规则 |
|------|--------|---------|---------|
| 权益市场分析 | WebSearch | 交易日 15:30 后搜索"A 股市场总结" | "外部短评暂未获取" |
