# 研究发现

## O32 字段 → 日报字段映射

> 从 `scripts/data_collector.py` 提取的实际使用字段。

| O32 字段 | 类型 | 日报栏目 | 用途 |
|---------|------|---------|------|
| `业务分类` | VARCHAR | 交易额度汇总 | 分组维度（交易所业务/银行间业务等） |
| `委托方向` | VARCHAR | 交易额度汇总 | 分组维度 |

### 委托方向取值说明

| 取值 | 含义 | 适用业务分类 |
|------|------|-------------|
| `债券买入` | 债券买入 | 交易所业务、银行间业务 |
| `债券卖出` | 债券卖出 | 交易所业务、银行间业务 |
| `融资` | 融入资金（正回购） | 交易所业务、银行间业务 |
| `融券` | 融出资金（逆回购） | 交易所业务、银行间业务 |
| `买入` | 个股买入 | 仅交易所业务（权益类） |
| `卖出` | 个股卖出 | 仅交易所业务（权益类） |

> **注意**：「债券买入/卖出」与「买入/卖出」是不同业务。前者是债券交易，后者是股票交易。分组统计时需保留完整名称，不可简写。
| `指令状态` | VARCHAR | 交易额度汇总 | 过滤条件（排除"撤销"） |
| `指令金额` | NUMBER | 交易额度汇总 | 金额列（SUM） |
| `成交金额` | NUMBER | 交易额度汇总 | 金额列（SUM） |
| `指令下达时间` | NUMBER | 交易笔数 | 按小时分组（HHMMSS → 小时） |
| `指令价格 (回购为利率)` | NUMBER | 交易价格汇总/趋势预测/区间预测 | 利率值（AVG/MAX/MIN） |
| `回购天数` | NUMBER | 交易价格汇总 | 品种分类（1=R001, 7=R007, 14=R014） |

### 聚合逻辑

| 日报栏目 | 聚合方式 | 代码函数 |
|---------|---------|---------|
| 交易额度汇总 | GROUP BY (业务分类 + 委托方向), SUM(指令金额), COUNT(*) | `aggregate_trade_overview()` |
| 交易笔数 | GROUP BY HOUR(指令下达时间), COUNT(*) | `aggregate_trade_count_by_hour()` |
| 交易价格汇总 | GROUP BY 回购天数，AVG/MAX/MIN(指令价格) | `aggregate_trade_prices()` |

### 数据缺口

| 日报栏目 | 缺口 | 说明 |
|---------|------|------|
| 权益市场分析 | 无 O32 权益类指令 | O32 以债券回购为主，无股票/基金指令 |
| 趋势预测/区间预测 | 无历史时序数据 | 当前用当日数据简化展示 |

## QT 短评字段映射

| QT 字段 | 类型 | 日报栏目 | 用途 |
|---------|------|---------|------|
| `CONTENT` | VARCHAR | 资金市场/现券市场/一级市场分析 | 短评原文 |
| `MSG_SEND_NAME` | VARCHAR | 同上 | 发送人 |
| `CHANNEL` | NUMBER | 同上 | 频道（1=森浦, 3=通达信, 4=快确） |
| `MSG_DATE` | NUMBER | 同上 | 日期过滤 |
| `MSG_TIME` | NUMBER | 同上 | 时间排序 |

### 分类关键词

- **资金面**：回购、资金、头寸、融出、融入、R001/R007、利率、央行、逆回购、MLF、OMO
- **现券**：现券、债券、收益率、估值、成交、国债、政金债、信用债、BP、YTM
- **一级发行**：一级、发行、投标、新债、招标、边际、倍率、募
- **权益市场**：❌ 无（需 WebSearch）
