# Template Contract：参考模板交易日报 v0.1

> 本文件是当前版本的具体规格，可随实现和参考图理解持续调整。每次调整必须基于证据，并同步更新 `state.md`。

## 参考材料

| 文件 | 用途 |
|------|------|
| `reference/目前交易日报某日输出.jpg` | 标题、版式、栏目、段落、表头、图表位置和输出风格模板 |
| `reference/查找外部现券资金短评方式.txt` | 资金面/现券/一级发行外部短评获取方式 |
| `findings.md` | 字段映射、数据源能力、数据缺口、降级规则 |

## 总体版式

- 输出仍为 HTML，路径保持 `reports/YYYY-MM-DD-daily.html`。
- 主体应接近参考图的窄幅长图结构：蓝色背景、左侧时间线、白色内容块、蓝色标题标签。
- 不使用桌面 dashboard 式多卡片主结构作为最终目标。
- 移动/长截图视角优先，宽屏展示只是兼容项。

## 主模板栏目

| 顺序 | 参考模板区域 | 必须出现的标题/子标题 | 数据源 | 验收要点 |
|------|-------------|----------------------|--------|----------|
| 0 | 标题区 | `创金合信基金交易部`、`YYYY年M月D日`、`交易日报` | 自动生成 | 标题层级和日期格式贴近参考图 |
| 1 | `01 交易数据汇总` | `交易数据汇总`、`交易笔数`、`交易金额` | O32 指令 | 三个子块归入同一个 `01` 区域 |
| 2 | `02 交收数据汇总` | `交收数据汇总` | 进度汇总 API | 名称用 `交收数据汇总` |
| 3 | `03 市场预测汇总` | `市场预测汇总`、`趋势预测准确率`、`区间预测准确率` | 回购行情 + 历史预测数据 | 无历史时显示明确占位，不得把当日利率伪装成准确率 |
| 4 | `04 资金市场分析` | `资金市场分析`、`公开市场操作`、`资金面状况` | 资金事件日历 + QT 资金面 | 含公开市场操作、资金面状况子块 |
| 5 | `现券市场分析` | `现券市场分析` | QT 现券短评，外部短评可补充 | 独立栏目 |
| 6 | `权益市场分析` | `权益市场分析` | WebSearch 获取 A 股闭市总评 | WebSearch 不可用时显示 `外部短评暂未获取` |
| 7 | `一级市场分析` | `一级市场分析`、`发行情况`、`发行结构分析` | QT 一级发行短评暂代，外部数据源待接入 | 含发行情况、发行结构分析子块 |
| 8 | `风险提示` | `风险提示` | 固定合规提示 + 必要的动态风险摘要 | 红色编号提示是主内容；规则引擎风险表不替代该栏目 |

## 数据填充规则

1. 优先使用当日 O32 指令数据。
2. QT 聊天只用于资金面、现券、一级发行等可明确分类的市场短评。
3. 权益市场分析采用 AI 执行期 WebSearch 获取当日 A 股闭市总评；纯脚本运行或搜索失败时必须降级为 `外部短评暂未获取`。
4. 缺失数据不得编造，按栏目使用固定占位：
   - `暂无相关数据`
   - `暂无成交`
   - `暂无有效消息`
   - `外部短评暂未获取`
   - `今日休市，无交易数据`
5. 趋势/区间预测准确率没有历史预测数据时，只能显示 `历史预测数据不足，暂无法计算准确率`，不能用当日 O32 利率替代准确率。

## 验收标准

每次实现后必须提供证据。

### 生成命令

```powershell
$env:PYTHONIOENCODING='utf-8'
uv run python scripts/generate_report.py --date 20260617
```

### 主标题顺序

抽取生成 HTML 的可见主标题，结果应按下列顺序出现：

```text
创金合信基金交易部
交易日报
01 交易数据汇总
交易数据汇总
交易笔数
交易金额
02 交收数据汇总
03 市场预测汇总
趋势预测准确率
区间预测准确率
04 资金市场分析
现券市场分析
权益市场分析
一级市场分析
风险提示
```

### 视觉检查

- 主体是窄幅长图式报告，不是宽屏 dashboard。
- 参考模板主栏目顺序没有被 `市场短评`、`账户头寸`、`风险预警` 打断。
- 缺失数据使用固定占位，没有编造内容。
- 生成文件可在浏览器中正常打开，无明显文本重叠。
