# Template Contract：参考模板交易日报 v0.1

> 本文件是当前版本的具体规格，可随实现和参考图理解持续调整。每次调整必须基于证据，并同步更新 `state.md`。

## 参考材料

| 文件 | 用途 |
|------|------|
| `reference/目前交易日报某日输出.jpg` | 标题、版式、栏目、段落、表头、图表位置和输出风格模板 |
| `reference/查找外部现券资金短评方式.txt` | 资金面/现券/一级发行外部短评获取方式 |
| `findings.md` | 字段映射、数据源能力、数据缺口、降级规则 |

## 总体版式

- 输出仍为 HTML，路径保持 `reports/YYYY-MM-DD-daily.html`。
- 主体应接近参考图的窄幅长图结构：蓝色背景、左侧时间线、白色内容块、蓝色标题标签。
- 不使用桌面 dashboard 式多卡片主结构作为最终目标。
- 移动/长截图视角优先，宽屏展示只是兼容项。

## 主模板栏目

|------|-------------|----------------------|--------|----------|
| 0 | 标题区 | `创金合信基金交易部`、`YYYY年M月D日`、`交易日报` | 自动生成 | 标题层级和日期格式贴近参考图 |
| 1 | `01 交易数据汇总` | `交易数据汇总`、`交易笔数`、`交易金额` | O32 指令 | 三个子块归入同一个 `01` 区域 |
| 2 | `02 交收数据汇总` | `交收数据汇总` | 进度汇总 API | 名称用 `交收数据汇总` |
| 3 | `03 市场预测汇总` | `市场预测汇总`、预测结论、预测指标、方法说明 | O32/QT + 外部市场数据源 | 必须给出可解释预测；无指标数据时先查找并记录外部源，不做准确率栏目 |
| 4 | `04 资金市场分析` | `资金市场分析`、`公开市场操作`、`资金面状况` | 资金事件日历 + QT 资金面 | 含公开市场操作、资金面状况子块 |

| 7 | `一级市场分析` | `一级市场分析`、`发行情况`、`发行结构分析` | QT 一级发行短评暂代，外部数据源待确定 | 含发行情况、发行结构分析子块 |
| 8 | `风险提示` | `风险提示` | 固定合规提示 + 必要的动态风险摘要 | 红色编号提示是主内容；规则引擎风险表不替代该栏目 |

## 数据填充规则

1. 优先使用当日 O32 指令数据。
2. QT 聊天只用于资金面、现券、一级发行等可明确分类的市场短评。
3. 权益市场分析采用 AI 执行期 WebSearch 获取当日 A 股闭市总评；纯脚本运行或搜索失败时必须降级为 `外部短评暂未获取`。
4. 缺失数据不得编造，按栏目使用固定占位：
   - `暂无相关数据`
   - `暂无成交`
   - `暂无有效消息`
   - `外部短评暂未获取`
   - `今日休市，无交易数据`
5. 市场预测必须基于可说明的数据和方法，不得把当日利率、截图占位或空表伪装成预测。
6. 当前版本不做 `趋势预测准确率` 和 `区间预测准确率`，这两个栏目从主模板目标中移除；后续积累预测记录后再新增准确率复盘。
7. 预测所需指标若 O32/QT 无法提供，应查找允许使用的外部来源；来源一经确定，必须记录到 `findings.md`，包括来源名称、获取方式、字段、用途和降级规则。

## 市场预测验收

`03 市场预测汇总` 必须输出可读、可解释、可追踪的预测，不再以准确率占位作为目标。

当前至少包含：

- **资金面预测**：预测下一交易日资金面方向（偏松/均衡/偏紧），指标可包括 DR001/DR007、R001/R007、OMO 净投放、政府债缴款、同业存单/大额到期、QT 资金面情绪。
- **现券市场预测**：预测利率债/信用债收益率方向或交易情绪，指标可包括国债收益率曲线、活跃券成交/收益率、资金利率、QT 现券情绪。
- **风险/不确定性**：列出影响预测的主要风险，例如央行操作、缴款扰动、海外利率、权益市场风险偏好。

每个预测必须包含：

| 要素 | 要求 |
|------|------|
| 预测结论 | 明确方向或区间，不写空泛判断 |
| 关键指标 | 列出实际使用的指标；没有指标则不能标为已验证 |
| 方法论 | 说明如何从指标得到预测，例如资金缺口、利率变动、情绪占比、事件扰动 |
| 数据来源 | O32/QT/外部源逐项标明；外部源记录到 `findings.md` |
| 降级规则 | 指标缺失时说明缺口，不编造预测 |

## 市场分析内容验收

`04 资金市场分析`、`现券市场分析`、`一级市场分析` 不能只凭 section 存在或降级占位视为完成。

- 资金市场分析：有 QT 资金面短评时，应输出成段市场研判，至少包含资金面情绪、主要关注点、代表性报价/观点；有资金事件数据时还应显示公开市场操作和债券发行/到期数据。
- 现券市场分析：有 QT 现券短评时，应对多人观点去重整合，输出市场情绪、关注品种/期限、代表性成交或报价，不应只罗列原始消息。
- 一级市场分析：有 QT 一级发行短评时，应整理为发行情况分析；`发行结构分析` 若无结构化数据源，必须明确 `暂无相关数据`，不能伪造发行结构。
- 文案质量要求：段落应像正式日报，可被业务读者直接阅读；避免“无高频关键词”“共 N 条短评”这类机器过程描述作为主体结论，除非放在证据或脚注中。
- 正式报告中这些栏目只有降级占位时，状态最多为 `已渲染`，不能标为 `已验证`。

## 验收标准

每次实现后必须提供证据。

### 生成命令

```powershell
$env:PYTHONIOENCODING='utf-8'
uv run python scripts/generate_report.py --date 20260617
```

### 主标题顺序

抽取生成 HTML 的可见主标题，结果应按下列顺序出现：

```text
创金合信基金交易部
交易日报
01 交易数据汇总
交易数据汇总
交易笔数
交易金额
02 交收数据汇总
03 市场预测汇总
04 资金市场分析
现券市场分析
权益市场分析
一级市场分析
风险提示
```

### 视觉检查

- 主体是窄幅长图式报告，不是宽屏 dashboard。
- 参考模板主栏目顺序没有被 `市场短评`、`账户头寸`、`风险预警` 打断。
- 缺失数据使用固定占位，没有编造内容。
- 生成文件可在浏览器中正常打开，无明显文本重叠。
